# 📊 Customer Behavior Analysis

## 📌 Overview
This project focuses on analyzing customer shopping behavior using Python, SQL, PostgreSQL, and Power BI. The project includes data preprocessing, exploratory data analysis (EDA), SQL-based analysis, dashboard visualization, and reporting to uncover meaningful customer insights and business patterns.

The final outcome includes an interactive Power BI dashboard, SQL analysis, project report, and presentation.

---

# 🎯 Project Objectives
- Analyze customer shopping behavior data
- Perform data cleaning and preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Store and query data using PostgreSQL
- Generate insights using SQL queries
- Build an interactive Power BI dashboard
- Present findings through reports and presentations
